# Clinical Alarm Management Simulator

An educational biomedical engineering project focused on understanding
patient-monitoring signals, alarm behavior, signal artifacts,
alarm-management concepts, troubleshooting, and clinical/product workflows.

## Target Roles

- Clinical Application Specialist
- Product Specialist
- Technical/Application Support

## Project Objective

The project will use retrospective physiological waveform data and a
simplified alarm simulator to explore how physiological measurements,
signal quality, persistence, and cross-parameter consistency can affect
patient-monitor alarm behavior.

The project will also include troubleshooting case studies, commercial
patient-monitor study, clinical user-training exercises, and product
demonstration practice.

## Current Status

Phase 1: Development environment and project foundation.

## Disclaimer

This is an educational engineering project.

It is not a medical device, has not undergone clinical or regulatory
validation, and must not be used for patient diagnosis, treatment,
monitoring, or clinical decision-making.
